# 参考 · 配置

> 本文件由脚本从源码生成，**不要手改**；改代码/配置后重跑 `uv run python tools/gen_docs.py`。
> 生成口径：命令行取 `argparse` 解析树，配置取 `CONFIG_SCHEMA_KEYS` + 示例文件 + `Config` 默认值，
> 接口取 FastAPI 应用的 `app.routes`（一次性构建在临时空库上，不联网）。

共 **60** 个键，分 **10** 段。加载顺序：

```
代码默认值  <  config 文件  <  环境变量 KNOWATLAS_<段>_<键>
```

配置文件路径默认 `config/knowatlas.toml`（相对当前目录），可用环境变量 `KNOWATLAS_CONFIG` 指定任意路径（**已支持**）。

类别：**D** 部署参数 · **S** 秘密 · **T** 领域阈值 · **I** 实现常量（见文末）。

「代码默认」有值 = 该键有 `Config` 属性（不写配置也生效）；「—」= 只有代码内默认。

## 秘密（S 类，不在配置文件里）

密钥/令牌只从环境变量读，配置文件只写变量名（`*_env`）。

| 环境变量 | 用途 |
|---|---|
| `KNOWATLAS_LLM_API_KEY` | LLM 主 key（DeepSeek 等） |
| `KNOWATLAS_LLM_API_KEY_SF1` / `_SF2` | 备用 LLM key（多后端轮换） |
| `KNOWATLAS_WEB_TOKEN` | Web 写操作令牌 |
| `KNOWATLAS_HOME` | 数据根（覆盖 `general.db_path` 的相对基准） |
| `KNOWATLAS_CONFIG` | 指定配置文件路径 |
| `KNOWATLAS_SOFFICE_PATH` | 旧版 Office 转换后端（可选） |

## 实现常量（I 类，不开放）

| 常量 | 位置 | 为什么不开放 |
|---|---|---|
| 清洗阈值（页码占比、目录点线、重复行、推广窗口） | `pipeline/clean.py::CleanThresholds` | 从 5.9 M 字符真实语料量出；开放会变成「可配置成洗不干净」 |
| 自洽性闸门阈值（裸名词/截断/代码块未闭合） | `pipeline/point_gate.py` | 它定义「什么算合格知识点」，可调等于什么都能过 |
| EOL 表（技术与版本 → 停产日期） | `semantic/eol.py::EOL` | 数据驱动，更新走工单；放配置会让判据版本不可追溯 |
| 点分诊/老化批大小（AGING_BATCH 等） | `pipeline/aging.py、lifecycle.py` | 性能参数，跟数据量有关，按需改代码 |
