# 变更工单：远程嵌入提供方（semantic search 开关）

## 1. 为什么

混合检索（FTS + 向量余弦 RRF，`/api/search?mode=hybrid`）2026-10-25 之前只有
`provider="local"` 一条路：要装 `sentence-transformers`（torch 约 2.5 GB）并下载
bge-m3（约 2.2 GB），本机未装 → `point_vectors` / `entry_vectors` 长期 0 行，
前端请求的 `mode=hybrid` 一直静默降级为 FTS。

硅基流动等 OpenAI 兼容 `/embeddings` 接口可用（实测 `BAAI/bge-m3` 1024 维、0.4 s），
4552 个点的建库成本约 ¥0.2、耗时 1–2 分钟，且不引入 torch。

## 2. 改什么

| 位置 | 改动 |
|---|---|
| `src/knowatlas/semantic/embed.py` | 新增 `RemoteEmbedder`（OpenAI 兼容，批量切片 + 归一化 + 重试）；`from_config` 支持 `provider ∈ {openai, remote, siliconflow}` |
| `config/knowatlas.example.toml` | `[embedding]` 注释补远程键（示例值注释掉） |
| `config/knowatlas.toml`（本机，gitignore） | 切到硅基流动 `BAAI/bge-m3`，`enabled=true` |
| `tests/test_embed_remote.py` | 新增 7 项：key 缺失降级、构建、禁用/未知 provider、批量+归一化、空输入、重试后抛错、条数不符 |

### 契约核对

| 契约 | 是否变化 |
|---|---|
| 表结构（`entry_vectors` / `point_vectors`） | **否**，表早已存在（第五十六批） |
| REST 接口签名（`/api/search`） | **否**，`mode=hybrid` 早已存在 |
| `SOURCE_TYPES` / `STATUSES` / locator scheme | **否** |
| `CONFIG_SCHEMA_KEYS`（只校验段名） | **否**；`[embedding]` 段名不变，新增的是段内自由键 |
| 能力注册（`registry/builtins.py`） | **否**，未新增 task |

## 3. 实现要点

- `RemoteEmbedder.encode(texts)`：按 `batch_size` 切片，逐批 POST
  `{base_url}/embeddings`，`Authorization: Bearer <api_key_env 读到的值>`；
  结果按 `normalize()` L2 归一化（与本地实现同契约，库内余弦 = 点积）。
- `dim` 可配置也可留空：首批发回后自动回填；**换模型必须 `ksync --embed --embed-force`**
  （维度变化会让旧向量失效，不做静默混用）。
- 降级：`enabled=false` / key 未设 / `base_url`/`model` 缺 → `from_config` 返回 `None`，
  检索退回 FTS，不报错、不阻断启动（与 LLM 同构）。
- 重试：网络/HTTP/条数不符统一重试 3 次（间隔 1.5s/3s/4.5s），最终抛 `RuntimeError`。

## 4. 验证

1. `uv run python -m pytest tests/test_embed_remote.py tests/test_embed.py -q` → 32 passed。
2. `uv run python -m knowatlas ksync --embed` → `point_vectors` / `entry_vectors` 行数 = 点数/条目数。
3. 语义词检索：FTS 零命中、hybrid 能召回（`via_sim` 标向量独有点）。
4. `uv run python -m pytest tests/test_canary.py -q` → 绿（能力规格未动）。

## 5. 已知边界

- 远端接口依赖网络与 key；离线场景仍可切回 `provider="local"`。
- 不同模型的向量不可混用；切模型 = `--embed-force` 全量重建（4552 点约 1–2 分钟）。
- 成本随语料线性增长；当前规模（4552 点 + 221 条目）约 ¥0.2/次全量。
