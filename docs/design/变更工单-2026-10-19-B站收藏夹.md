# 变更工单：B站收藏夹接入

## 触发输入（用户 2026-10-19）

1. 问：B站收藏夹能不能读。
2. 立规：所有需要账号密码的一律用配置文件（B站为首个 cookie 型凭证源，立为模板）。
3. 网络核查结论（2026-10-19）：
   - 接口：收藏夹列表 `GET api.bilibili.com/x/v3/fav/folder/created/list-all?up_mid=<UID>`；内容 `GET /x/v3/fav/resource/list?media_id=<fid>&pn&ps&order=mtime`，`has_more` 判结束，媒体项含 title/intro/bvid/pubtime/fav_time/owner。
   - 凭证：SESSDATA cookie（+ DedeUserID 识别用户）；私有收藏夹必须登录；有效期约 30 天。
   - WBI 签名：fav 路径当前不含 `/wbi/`，不需要；但可能后加 → 内置可开关 WBI 模块（参照 bili-sync）。
   - 错误码：72010002 / -403 = 凭证失效；412 = 风控；视频下架项保留标题级。
   - 请求头需 UA + Referer（space.bilibili.com），频率 ≤2 QPS。
   - 开源蓝本：bili-sync（amtoaer，Rust）。
