## 3. 坑（换会话必看）

- **LLM key**：用户级环境变量存在，但本机 agent shell 早于 `setx` 启动 → 每条需要 LLM 的命令先导入：
  ```powershell
  foreach ($n in 'KNOWATLAS_LLM_API_KEY_SF1','KNOWATLAS_LLM_API_KEY','KNOWATLAS_WEB_TOKEN') {
    $v = [Environment]::GetEnvironmentVariable($n,'User'); if ($v) { Set-Item -Path "env:$n" -Value $v }
  }
  ```
  没导入时 `kpoints` 会退化成「4,023 字整篇照抄」，CLI 现在会打 WARN（R10）提示。
- **搜索只认"点"和标题**（批 92 裁决）：`/api/search` 不出全文概要。**点没抽出来，搜什么都是空的**——页面看着"没效果"通常不是抓取问题，是抽点没跑。
- **PDF 双通道**：`auto` 只在 `>30 MB 或 >1500 页` 时走 PDFium。**别把阈值调小**——pdfium 对 `agentic-ai-guide` 只取到 30% 字符、`AI-Agents-in-Depth` 43%（实测），它只是逃生通道。
- **`agentic-design-patterns` 保留率 0.856**：这是正常的（页码多），闸门已按 0.80 放行；`_clean_options` 的兜底值必须取 `CleanThresholds()` 默认，别另抄数字（踩过一次，清洗跑了但库没变）。
- **推不上去**：`origin` 走 ghproxy 只读镜像，本地提交正常，push 会失败（等直连恢复后取消 `url.…insteadOf`）。
- **GBK 控制台**：中文先 `$env:PYTHONIOENCODING='utf-8'` + `[Console]::OutputEncoding=[Text.Encoding]::UTF8`。
