## 5. 维护约定

- **状态标注**：本文状态列只写「已落地 / 未落地 / 待裁决」三态；数字与现场证据放 `docs/log.md`，
  不往本文搬，避免过期。
- **新增文档**：方案/调研写日期后缀；工单写 `变更工单-YYYY-MM-DD-主题.md`，并在本文第 2 节补一行。
- **文档不写死数字**：基线、条数、耗时这类会变的东西，写「怎么取」而不是「当时是多少」。
