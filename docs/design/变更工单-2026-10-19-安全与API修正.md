# 变更工单：安全与 API 修正（H5）

## 触发输入

评审 H5：Web API 两个具体缺陷——

1. `GET /api/categories/{path}/entries` 的 path 含斜杠（如"软件/ERP/仓存管理"），FastAPI 默认 path 参数不跨 `/`，**必然 404**。
2. 仅绑 127.0.0.1 挡不住 CSRF 和 DNS rebinding——浏览器里随手访问的任意网页都能往本地库灌条目、并触发 DeepSeek Fetch 计费。

用户决策：与契约返工分开，单独一页工单。

## 范围划分

- path 参数修正（`{path}` → `{path:path}`）已在《契约返工》C13 落盘，本工单不重复，探针一并复检。
- 本工单覆盖安全三项：Host/Origin 校验、写操作本地 token、content-type 白名单。
